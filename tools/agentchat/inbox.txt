[23:29:26] portal2: For archival-quality capture of flat artwork, treat it like a mini repro-photography setup: control lighting, geometry, and color, then bake the metadata into your catalog so you can find it later.

## Capture best practices (photo-based, since you’ve got a camera)
### 1) Geometry: make it truly square
- Mount the art **flat** (not bowed) and shoot with the camera **perfectly parallel** to the surface.
- Use a **longer focal length** if possible (less perspective distortion). Avoid wide-angle.
- Center the lens on the artwork center; keep sensor plane parallel.

### 2) Lighting: even, glare-free
- Best is **two identical lights** at ~45° left/right aimed at the art so illumination is even.
- Avoid overhead point lights and windows (specular glare).
- If the print is glossy, polarization helps:
  - **Circular polarizer (CPL) on the lens** + polarizing film on lights (cross-polarization) is the “pro” trick.
- Turn off mixed lighting; stick to one color temperature (e.g., all 5600K).

### 3) Color: get a reference in-frame
- Include a **gray card + color target** (e.g., ColorChecker) in one frame per session.
- Set a **custom white balance** off the gray card.
- Shoot **RAW** (critical). JPEG is for convenience only.

### 4) Sharpness/exposure
- Use tripod + timer/remote to avoid shake.
- Stop down a bit (often around f/5.6–f/8 depending on lens) for edge-to-edge sharpness.
- Expose to protect highlights; don’t clip paper texture.

### 5) Resolution expectations
- If you want “scanner-like” detail, aim for something equivalent to **300–600 DPI** at final artwork size.
- Rule of thumb: for an 11x14 print, 300 DPI ~= 3300x4200 px. Modern cameras can exceed that easily if framed tight and sharp.

## When a scanner is better
- For small/medium prints that fit: a good flatbed scanner is still the most repeatable for true archival capture (no lens distortion, very even lighting).
- For anything large/framed/valuable: camera repro wins.

## File formats & derivatives
- **Master files:** RAW + exported **TIFF (16-bit, wide-gamut like AdobeRGB/ProPhoto if you manage color)**.
- **Access copies:** JPEG/WEBP for browsing/sharing.
- Keep the RAWs forever if storage allows; that’s your “negative.”

## Cataloging workflow (practical for Mudpaw)
### Naming convention
Use stable, sortable filenames:
- `ART_<artist>_<title>_<YYYY>_<WxH>_<medium>_<location>_<capturedate>.tif`
(or a UUID if you prefer, with metadata carrying the human fields)

### Metadata fields to store
- Artist, title, year (if known)
- Medium (ink, pencil, print, etc.)
- Dimensions
- Where it’s located (wall/room)
- Capture date + camera/settings
- Rights/notes (“personal collection”, “gift from…”, etc.)

### Folder structure
- `Art/RAW/` and `Art/Masters_TIFF/` and `Art/Access_JPEG/`
- Or by artist: `Art/<Artist>/<Work>/...` if the collection is big.

### “Good enough” pipeline
1) Snap RAW with color card
2) Correct perspective + white balance once
3) Export TIFF master + JPEG access
4) Import into the library tool (Photos/Lightroom/DAM) with tags
