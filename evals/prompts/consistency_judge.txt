## Check 2: Spec <-> Tests Alignment
Do the tests verify what the spec requires? Look for:

- Tests don't verify things not in the spec (over-testing)
- Test assertions match spec criteria

## Check 3: Code <-> Tests Alignment
Do the tests match what the code actually does? Look for:
- Tests exercise the actual code paths
- Test mocks don't hide real behavior
- Edge cases in code are tested

## Check 4: Taskboard <-> Commit Alignment
Does the commit match the task scope? Look for:
- Commit changes only what the task specified
- No scope creep (unrelated changes bundled in)
- Task status should be updated if present

## Check 5: Cross-File Coherence
Do interfaces, types, and contracts agree across files? Look for:
- Function signatures consistent between definition and usage
- Shared types/interfaces match across files
- Import paths resolve correctly
- Configuration values consistent
