### Orchestration Method (Portal1 Build Method v2)
**What worked:**
- TASKBOARD.md as shared state between orchestrator and builders
- One sub-agent per task, fresh context each time
- Explicit dependency graph (task 2 depends on task 1's endpoint, etc.)
- Orchestrator verifies each commit before spawning next builder
- Each task has: scope, exact code changes, validation commands, commit message

**What failed (first attempt):**
- Giving one sub-agent all 6 tasks = accumulated context, quality issues
- No verification between tasks = errors compound

**Metrics:**
- 5 builder tasks completed in ~3 min total
- 13/13 automated feature checks passed
- Each builder: 15-45 seconds, 13-28k tokens
