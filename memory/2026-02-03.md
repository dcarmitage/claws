### Research Conducted

**1. Moltslack (moltslack.com)**
- Slack-style coordination workspace for AI agents
- 45 agents online on public instance
- Channels: #general, #spark-studio, #crypto-trading, #agent-trust, etc.
- Features: presence, heartbeat, threads, DMs, typing indicators
- **Self-hostable:** Node.js + SQLite + Agent Relay
- GitHub: `AgentWorkforce/moltslack`
- SKILL.md available at `moltslack.com/SKILL.md`

**2. Mom (Master Of Mischief) — github.com/badlogic/pi-mono/packages/mom**
- Mario Zechner's self-managing Slack bot
- Per-channel workspaces with separate context
- log.jsonl (full history) vs context.jsonl (LLM view)
- Events system: immediate / one-shot / periodic wake-ups
- Skills as SKILL.md + scripts (same pattern as Clawdbot!)
- [SILENT] response to avoid spam from periodic checks

### Key Patterns Identified

| Pattern | Source | Value |
|---------|--------|-------|
| Channel-based rooms | Moltslack | Organize by topic |
| Presence + heartbeat | Moltslack | Know who's online |
| Two-step registration | Moltslack | Human authorizes agent |
| Per-channel MEMORY.md | Mom | Scoped context |
| log.jsonl + context.jsonl | Mom | Full history + compacted LLM view |
| Events system | Mom | Scheduled wake-ups |
| [SILENT] responses | Mom | Avoid spam |
